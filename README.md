## 📈 Mon parcours : apprendre l'informatique de zéro

👉 **[mon-parcours](https://github.com/anicetmiz/mon-parcours)** rassemble mes projets du cégep, **dans l'ordre où je les ai appris**. Ça commence par ma toute première page HTML et ça va jusqu'aux applications complètes en C#, avec une base de données, une API REST et une interface.

J'ai construit ce dépôt pour **aider ceux qui veulent apprendre l'informatique en partant de zéro**. Chaque projet a un README écrit pour un débutant : ce que fait le projet, comment le lancer, les notions expliquées avec des exemples tirés du code, et souvent les étapes pour le refaire seul.

En le suivant du début à la fin, on passe par les mêmes étapes que moi, jusqu'au **niveau d'un stagiaire en développement** : être capable de créer une application complète (interface, logique et base de données) et de travailler en équipe avec Git.

```
HTML/CSS → POO (Java) → JavaScript → SQL → C# + Entity Framework → MVVM → API REST → Vue.js → Kotlin → ASP.NET Core MVC
```
